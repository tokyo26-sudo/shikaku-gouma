ダイヤル

回すもの
輪っかの記号を押すと、選んだ能力の最強をそこに置く。←→キーでも回せる
ためし
輪っかの並び順（0〜9・X・Y の12こ）

点のつけ方：最強の記号が 12点。そこから時計回りに1つ進むごとに1点ずつ下がる（最強のすぐ左どなりが 1点）。
記号：右上の 0 → X（亠か もう使った か不明）、左下・右下の 0 → Y（もう使った）。左上の 0 はそのまま（必ず頭の形）。
輪っかの小さい数字は、選んだ能力の隅でその記号が出る割合（下の「範囲」の字で数える）。点線の記号はその隅には出てこない。

見る字

漢字を入れるとレーダーチャートが出る。点線のひし形は、範囲の字の平均。号碼が2つある字は1つ目を使う。
