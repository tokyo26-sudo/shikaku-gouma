四角号碼の説明と使い方

四角号碼とは

漢字の四つの隅の形を、0〜9 の数字に置きかえて 4桁の番号にしたものです。1920年代に中国の王雲五が考え、漢和辞典の索引などで使われてきました。読み方や部首がわからない字でも、形を見るだけで引けるのが特長です。

番号のつけ方

  1. 左上 → 右上 → 左下 → 右下 の順に、隅の形を見る
  2. それぞれの形を 0〜9 の数字にする（形と数字の対応は「部品の早見表」）
  3. 一度数えた筆画を、別の隅でもう一度は数えない。その隅は 0 にする
  4. 必要なら 5桁目に「附角」をつける。右下の隅のすぐ上にある筆画の形

品は 6066。左上は口で 6、右上は同じ口をもう数えたので 0、左下と右下は下の二つの口で 6 と 6。

このつーるの使い方

  • じびき
    • 号碼で引く：部品の ぼたん を左上から順に押すと、候補の漢字が しぼられていきます。数字を直接打っても、わからない隅を「?」で飛ばしてもかまいません
    • 漢字で引く：漢字を入れると、四隅に数字をそえて号碼を出します
  • れんしゅう
    • 号碼を答える：出た字の号碼を答えます。隅ごとに ○× がつきます。ぱそこん では数字きーでも入れられます
    • 漢字を答える：番号に合う字を、書くか 6つから選んで答えます
    • 範囲は「入門 107字」から「辞書ぜんぶ」まで。「形を隠す」で絵を消し、「?」で各数字の決まりを見られます
    • 結果は「成績一覧」に たまります。この端末の ぶらうざ に保存されます
  • カードあつめ：号碼を当てて漢字のカードを集めます（くわしくは下）
  • 部品の早見表：上の帯を押すと、0〜9 の形と字の例が開きます
  • 設定（歯車）：漢字の字体、画面の色味、カードのデザイン（ふつう・御朱印帳風・トレカ風）を選べます
  • データの保存：設定の「ファイルに保存」で、成績・カード・点・ガチャ券・設定を1つのファイルに書き出せます。別のパソコンやスマホで「ファイルから読み込む」と復活します

カードあつめ

  • 出てきた漢字の号碼を、4隅ぜんぶ正解するとカードが1枚もらえます。同じ字を当てるたびに枚数がふえます
  • 「答えを見る」を押したときや、まちがえたときは もらえません。問題をとばすこともできません
  • 範囲は「常用漢字」と「辞書ぜんぶ」から選べます
  • めずらしい字が出ると、画面が暗くなったり光ったりします
  • 集めたカードは右上の「コレクション」で見られます。並べかえができ、カードを押すと大きく表示、大きいカードを押すと裏返って読みなどが見られます
  • はじめてパック：カードが0枚の人は、無料で5枚入りの袋を1回だけ引けます（1枚は「少」以上）
  • ガチャ：れんしゅうで正解すると点がたまり、1000点でガチャ券1枚。券1枚で1枚入りの袋を引けます。点は 常用・辞書ぜんぶ 100点、入門・小学校 50点、「漢字を選ぶ」はその半分。まちがえても、四隅のどれか1つが合っていれば 10点（入門・小学校 5点）、全部ちがっても1点。「漢字を選ぶ」でまちがえたら1点。答えを見た問題は0点。点数の棒を押すと説明が出ます
  • 袋は上の点線を左から右へなぞると破れます（タップでも少しずつ破れる）。めずらしい字が入っていると、袋が光ります
  • いらないカードは、コレクションで大きく開いて「1枚すてる」「この字をぜんぶすてる」で消せます。カード・成績・点などを全部消して はじめからにするときは、設定（歯車）の「全部リセット」。どれも2回押すと消えます
  • カードはこの端末の ぶらうざ に保存されます

形ランク（★）　並・少・珍・稀・幻

漢字の四隅の数字の組み合わせが、どれくらいめずらしいかを表します。

それぞれの隅で その数字がどれくらいよく出るかを辞書の 7,914字で数え、4つの隅の割合をかけ算して「◯字に1字の形」を出しています。

燥は 9689。左上9・右上6・左下8・右下9 は どれも めったに出ない数字なので、かけ算すると 約31万字に1字の形 → 幻。
布（4022）は どの隅もよく出る数字で 約640字に1字 → 並。

  • 並 ★1：3千字に1字より ありふれた形
  • 少 ★2：3千〜8千字に1字
  • 珍 ★3：8千〜2万字に1字
  • 稀 ★4：2万〜5万字に1字
  • 幻 ★5：5万字に1字より めずらしい形

めずらしい形ほど出にくくなります。並を1とすると、
・カードあつめ（自分で当てる）：少 0.8倍・珍 0.7倍・稀 0.6倍・幻 0.5倍（常用漢字なら 稀か幻が 約15回に1回、幻は 約57回に1回）
・ガチャ：少 0.7倍・珍 0.5倍・稀 0.3倍・幻 0.15倍（幻は 約166回に1回）
※ 本当は隅どうしに つながりがあるので（左右が同じ形の字など）、ぴったりの確率ではなく「めずらしさの目安」です。

仲間ランク（札）　無双・双璧・精鋭・群雄・大群

同じ4桁の号碼をもつ字が、辞書（7,914字）に何字いるかを表します。仲間が少ないほど「唯一無二」です。

  • 無双：その号碼の字は1字だけ
  • 双璧：2字
  • 精鋭：3〜5字
  • 群雄：6〜19字
  • 大群：20字以上

形ランクとは別ものです。一（1000）は形はふつう（並）ですが、1000 の字は 一 だけなので 無双。山（2277）は形はめずらしい（幻）ですが、出・凶・幽 などの仲間がいるので 群雄です。カードあつめの出やすさには関係しません。

辞書について

号碼はウィクショナリー由来の辞書（7,914字）によります。辞書や流儀によって号碼がちがう字もあります。
